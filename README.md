# Gestionale Tabacchi & Cassa

Applicazione Web Mobile-Friendly per la gestione integrata di:
1. **Gratta e Vinci**: tracciamento giacenze pacchi e valore venduto.
2. **Ordini**: gestione fornitura e stati d'avanzamento (In Sospeso, Confermato, Consegnato, Annullato).
3. **Incassi**: registrazione entrate per categoria e metodo di pagamento (Contanti, POS, Bonifico).

## Pubblicazione rapida su GitHub Pages

1. Crea un repository su GitHub.
2. Carica il file `index.html`.
3. Attiva GitHub Pages dalle Impostazioni (`Settings` -> `Pages` -> Seleziona il branch `main` e salva).
